# Spam Message Detection

## About the Project
This project identifies whether a message 
is spam or not spam using Python and
Machine Learning.

## Technologies Used
* Python
* Scikit-learn
* Machine Learning
* Natural Language Processing (NLP)

 ## How It Works
 1. Take a text message as input.
 2. Process the message.
 3. Use a trained model to classify it.
 4. Display whether the message is spam or not spam.

 * Machine Learning model training
 * Spam message detection
